# "Your call" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the board a fourth view where decisions the agent made are recorded and decisions it could not make are held, so neither one has to become a stop in chat.

**Architecture:** A hand-written data file (`questions.js`) beside the board's other data files, a shared format module (`questions.mjs`) used by both the answer server and the staleness script so they cannot disagree about what a valid entry is, a dependency-free `serve.mjs` bound to loopback that rewrites one entry when an answer arrives, and a fourth tab in `index.html` that renders the list and posts answers. The board still opens from disk with no server — answering is the only part that needs one.

**Tech Stack:** Node's own `http`/`fs` (zero dependencies, matching the board's existing rule), plain browser JS in one HTML file, `node --test` for the format module.

**Spec:** `docs/superpowers/specs/2026-08-13-your-call-design.md`

## Global Constraints

- **Zero dependencies.** Nothing here may add a package. The board's promise is that it opens anywhere.
- **The board still opens from `file://`.** Every addition must render with no server running; only answering is gated on one.
- **`meanwhile` is required on every entry.** An entry without it is refused by `refresh.mjs`, which is the command the skill already tells everyone to run after an edit.
- **Bind `127.0.0.1` only.** This writes to disk on request.
- **8 KB body cap** on an answer.
- **An answered question is never re-answered** — a second thought is a new entry.
- **Two repos.** The template lives in `D:/VibeCode/ladder/skills/ladder-map/template/`; the live board is `D:/VibeCode/music-hub/docs/quality/`. They are byte-identical today and must stay so.
- **Bump `BOARD_VERSION`** in `index.html` to `'2026-08-13'` — a copied board has no other way to learn it is behind.

| File | Responsibility |
|---|---|
| `template/questions.js` (new) | The data. Hand-written by the agent, rewritten by the server when an answer lands. |
| `template/questions.mjs` (new) | The format: parse, check, answer. The only file that knows the shape. |
| `template/serve.mjs` (new) | HTTP: serve this directory, accept one answer. Knows nothing about the shape beyond calling `answerIn`. |
